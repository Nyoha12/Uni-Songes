Guide de contrôle · mobile et reflow

La même hiérarchie à 320 px

Réduire le viewport à 320 px transforme cet aperçu entier : le menu non fonctionnel devient un disclosure natif, les métadonnées passent en colonne et les URLs se replient sans défilement horizontal.

  • ordre de lecture et ordre DOM inchangés ;
  • cibles interactives d'au moins 44 px ;
  • focus visible et skip link conservés ;
  • aucune largeur fixe, image ou grille latérale.

Planche de revue propriétaire · aucune route, catégorie ou ressource réelle n'est créée par ce prototype.
